# Advanced Java Programs

This repository contains my **Advanced Java practical programs, JDBC programs, Servlet/JSP applications, and student registration projects** developed as part of my B.Tech Information Technology coursework.

## 📚 Contents

### 1. Java Web Applications
- FirstDemo
- SecondDemo
- ThirdDemo
- FourthDemo
- FifthDemo
- SixthDemo

These programs demonstrate basic Java web development concepts using **JSP, Servlets, form handling, request forwarding, and dynamic web pages**.

### 2. JDBC Programs
- JDBC Database Connection
- JDBC Student Insert Program
- Database Console Output
- Student table operations

The JDBC programs demonstrate how to connect a Java application with a **MySQL database** and perform database operations.

### 3. Student Registration System
- Student Registration
- Student Registration Output
- Form validation and result processing

This project demonstrates a basic **Student Registration and Validation System** using Java web technologies.

▶️ How to Run
Prerequisites

Install the following software:

Java JDK
Eclipse IDE
Apache Tomcat
MySQL Server
MySQL Connector/J
Steps
Clone this repository.
Open the project in Eclipse.
Configure Apache Tomcat.
Add the required MySQL Connector/J library.
Start MySQL Server.
Create the required database and tables.
Configure the database connection details.
Run the project using Run on Server.
Open the application in a web browser.
